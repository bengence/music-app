# Common Chord Progressions

## What are Chord Progressions?

Chord progressions are sequences of chords that form the harmonic foundation of songs. They're typically described using Roman numerals that represent the scale degree of each chord's root note.

## Most Popular Progressions

### I-V-vi-IV (1-5-6-4)
**Example in C Major:** C - G - Am - F
- **Used in:** Thousands of pop songs
- **Songs:** "Don't Stop Believin'" (Journey), "Someone Like You" (Adele)
- **Feel:** Uplifting, familiar, satisfying resolution

### vi-IV-I-V (6-4-1-5)
**Example in C Major:** Am - F - C - G
- **Used in:** Pop, rock ballads
- **Songs:** "Grenade" (Bruno Mars), "Complicated" (Avril Lavigne)
- **Feel:** Emotional, starts minor then resolves major

### I-vi-IV-V (1-6-4-5)
**Example in C Major:** C - Am - F - G
- **Used in:** Classic rock, doo-wop
- **Songs:** "Stand By Me" (Ben E. King), "Blue Moon"
- **Feel:** Classic, nostalgic, circular

### ii-V-I (2-5-1)
**Example in C Major:** Dm - G - C
- **Used in:** Jazz standards, classical music
- **Songs:** "All The Things You Are", "Autumn Leaves"
- **Feel:** Strong resolution, sophisticated

### I-IV-V (1-4-5)
**Example in C Major:** C - F - G
- **Used in:** Blues, rock, country
- **Songs:** "Wild Thing" (The Troggs), "La Bamba"
- **Feel:** Simple, driving, energetic

## Advanced Progressions

### iii-vi-ii-V-I (3-6-2-5-1)
**Example in C Major:** Em - Am - Dm - G - C
- **Used in:** Jazz, sophisticated pop
- **Feel:** Smooth, jazz-like movement

### I-bVII-IV-I (1-b7-4-1)
**Example in C Major:** C - Bb - F - C
- **Used in:** Rock, modal music
- **Songs:** "Sweet Child O' Mine" (Guns N' Roses)
- **Feel:** Rock, powerful, modal sound

### vi-ii-V-I (6-2-5-1)
**Example in C Major:** Am - Dm - G - C
- **Used in:** Jazz, classical
- **Feel:** Elegant, sophisticated resolution

## Progression Functions

### Tonic Function (Stability)
- **Chords:** I, vi, iii
- **Feel:** Home, rest, resolution

### Predominant Function (Preparation)
- **Chords:** ii, IV, vi
- **Feel:** Movement away from home, building tension

### Dominant Function (Tension)
- **Chords:** V, vii°
- **Feel:** Strong pull back to tonic, creates expectation

## Tips for Using Progressions

### For Songwriting:
1. **Start with popular progressions** - They work because they sound good
2. **Experiment with inversions** - Same chords, different bass notes
3. **Try substitutions** - Replace chords with similar function
4. **Add extensions** - 7ths, 9ths, sus chords for color

### For Practice:
1. **Learn in all keys** - Start with easier keys, gradually add sharps/flats
2. **Practice with different rhythms** - Same progression, different feels
3. **Use a metronome** - Keep steady time while changing chords
4. **Practice common transitions** - Focus on smooth voice leading

## Popular Keys for Progressions

### Guitar-Friendly Keys:
- **C Major** - No open chord challenges
- **G Major** - Natural guitar key
- **D Major** - Great for strumming
- **A Major** - Strong, bright sound

### Piano-Friendly Keys:
- **C Major** - All white keys
- **F Major** - One flat, comfortable hand position
- **G Major** - One sharp, natural feel

## Modern Variations

### Modal Progressions:
- **Dorian:** i-IV (Am-D in A Dorian)
- **Mixolydian:** I-bVII (G-F in G Mixolydian)

### Extended Chords:
- Replace triads with 7th chords: Cmaj7-Am7-Fmaj7-G7
- Add sus chords: Csus4-C-Fsus2-F

Remember: These progressions are starting points. The magic happens when you add your own rhythm, melody, and personal style!
